# ハーフサイズマイクロマウス：壁センサの部品

調査日：2026-10-25（日本時間）

ハーフサイズ機の作者README・大会公式テクニカルデータと、部品メーカーの製品情報を対応付けた資料です。価格・在庫、実機での検出距離は今回の確認対象にしていません。

## 1. 大まかな構成

反射型の壁センサは、**赤外線を出す部品 → 壁 → 反射を受ける部品 → 電圧として読み取る回路**で構成します。受光量は距離だけでなく、壁の反射特性、向き、周囲光にも左右されます。部品単体の仕様を、そのまま測距性能とは扱いません。

| 分類 | 部品 | 役割 | 必要性 |
|---|---|---|---|
| 発光 | 赤外線LED | 壁に赤外線を照射する | 反射型の基本部品 |
| 発光駆動 | MOSFET／トランジスタ、または定電流LEDドライバ | LEDを点灯・消灯し、電流を制御する | 駆動方式に応じて選ぶ |
| 電流設定 | 電流制限抵抗、ドライバの設定抵抗 | LED電流を設定する | 回路方式に応じて選ぶ |
| 受光 | フォトトランジスタ、またはフォトダイオード | 壁からの反射光を電流に変換する | いずれかを選ぶ |
| 受光信号処理 | 負荷抵抗、必要に応じてオペアンプ・帰還抵抗・コンデンサ | 光電流をADCで読める電圧にする、増幅・安定化する | 受光方式に応じて設計 |
| 電源安定化 | デカップリング／蓄電コンデンサ | 点灯時の電源変動を抑える | 回路・配置に応じて設計 |
| 読み取り | マイコン内蔵ADC、必要に応じて外付けADC | 受光信号を数値として読む | 読み取り手段が必要 |
| 実装・遮光 | 小基板、固定具、遮光板 | 発光・受光の向きを固定し、直接光や他chとの干渉を抑える | 機体の配置に応じて設計 |

上表の回路上の役割は一般的な整理です。下記のすべての機体に同じ回路・同じ周辺部品が使われていると主張するものではありません。

### フォトトランジスタとフォトダイオード

- **フォトトランジスタ**：素子内の増幅を利用でき、負荷抵抗で電圧として読む回路が候補になります。強い反射での飽和や、読み取りタイミングを確認します。
- **フォトダイオード**：光電流の読み取り回路を設計します。オペアンプで電流を電圧に変えるTIA方式などが候補で、帰還部品や帯域・安定性の検討が必要です。
- 機械寸法が似ていても、両者をそのまま同じ回路に差し替えられるとは限りません。応答速度の比較は素子だけでなく、負荷・増幅回路・ADCを含む系全体で行います。

## 4. 周辺回路の具体例

### BCR421UFD：定電流LEDドライバ

[Astraeaの作者README](https://github.com/Naophis/Astraea)では、LEDの定電流回路に**BCR421UFD**を使用したと記載されています。

[Diodes Incorporatedの製品情報](https://www.diodes.com/part/view/BCR421UFD)では、外部抵抗で電流を設定でき、EN端子で制御できるLED用定電流レギュレータです。**ドライバが供給できる電流と、LEDが許容する電流は別**なので、LEDの連続／パルス定格に合わせて設計します。

作者READMEには5Ωという記載もありますが、同じ値でよいとは限らないため、汎用の推奨抵抗値にはしません。電源電圧、LED順方向電圧、ドライバの必要電圧・損失、点灯時間をまとめて確認します。

### MOSFET＋抵抗などによる点灯

[白いハラシーマウスの設計記事](https://harattamouse.hatenablog.com/entry/2020/01/25/150801)では、コンデンサの充電時間を用いた発光強度調整について説明されています。記事にはPch MOSFETの極性訂正があるため、回路を参照する場合は訂正版の図を使用します。

## 6. 4ch構成を仮定した部品の数え方

前方2ch、左右各1chを例にした概算です。実際の向き・個数は機体ごとに決めます。

| 部品 | 数量の考え方 |
|---|---|
| 赤外線LED | 4個 |
| 受光素子 | 4個 |
| 発光駆動回路 | 個別制御なら4ch分。ICの個数は回路次第 |
| 電流設定・負荷抵抗 | 各chの回路に応じて決める |
| オペアンプ | 増幅方式と1パッケージ内の回路数次第。必須とは限らない |
| コンデンサ | 電源・受光回路・発光方式に応じて決める |
| 小基板・遮光・固定部品 | 光軸と機体の配置に応じて決める |

これは発注用BOMではありません。抵抗値・容量・電流・実装位置は、必要距離と回路設計を決めてから確定します。

## 7. 部品選定の進め方

1. 前壁検出、横壁制御、壁切れ検出など、各chの用途と必要距離を決める。
2. **部品単体ではなく、発光・受光・回路・取付角を一組として**参考機体を比較する。
3. リード型と表面実装型で、機体への収まりと製作方法を比較する。
4. LED点灯前後の値を使う周囲光補正や、ch間の点灯タイミングを検討する。
5. 近距離の飽和、遠距離の信号量、壁切れでの応答、ADCの整定を実際の壁で確認する。

最初の比較対象としては、複数の公開機体に採用情報がある**OSI5FU3A11C＋LTR-4206E**が資料を探しやすい組み合わせです。これは資料の多さに基づく整理であり、あらゆるハーフサイズ機に最適という結論ではありません。
